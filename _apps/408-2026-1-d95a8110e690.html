AR, Application Rate, (gallons per square yard)

AR=(RR/ARC)

This formula computes the Application Rate in gallons per square yard using the Residual Rate and the Asphalt Residue Content. As the Residual Rate increases, the Application Rate rises. Conversely, as the Asphalt Residue Content increases, the Application Rate falls.
